Telstra is Australia's largest telecommunications and mobile network operator, providing fixed broadband, mobile voice and data, enterprise networking, and IoT connectivity across Australia and into Asia. Telstra exposes a developer programme at dev.telstra.com fronting carrier-grade Messaging (SMS / MMS) and Mobile Number Verification APIs, with official SDKs in Python, Node.js, Java, .NET, and Go, and Arduino libraries for the Telstra Cat-1 and Cat-M1 IoT development kits. The dev.telstra.com catalogue also lists SIM Swap, Device Swap, KYC Match, KYC Tenure, Mobile Push Notifications, Bandwidth and Plan Modification, IoT Connectivity Service and Telstra Cloud Sight APIs, with a public API status page. APIs are reached at tapi.telstra.com behind OAuth 2.0 client credentials with the NSMS or MNV scopes.

**Areas:** Telecommunications · Mobile · Messaging · SMS · MMS · Networks · Australia · Verification

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Telstra: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
